**Case study:** AsterMart Retail & Fulfilment Ltd.

**Repository:** [https://github.com/timothyokooboh/advanced-database-portfolio](https://github.com/timothyokooboh/advanced-database-portfolio)

This repository contains the PostgreSQL, MongoDB, transaction, query-optimisation, and distributed-database implementation for the AsterMart portfolio.

The complete project overview, prerequisites, startup commands, validation commands, shutdown instructions, and links to each portfolio guide are provided in the [submission README](Okooboh_Timothy_301915902_README.md).

## Quick start

```bash
docker compose up -d
docker compose ps
```

The Compose environment initializes PostgreSQL 16 and MongoDB 7 with deterministic demonstration data. See the submission README for the complete verification sequence and the isolated logical-replication exercise.
